# With love by Nasra

Mobielvriendelijke website voor persoonlijke kaarten, cadeautjes, giftboxen en cadeauverpakkingen.

Live: https://umpreneur.github.io/with-love-by-nasra/

## Opbouw

Een statische website zonder server of database, gehost op GitHub Pages.

- `index.html`: de pagina met collectie, werkwijze en aanvraagformulier.
- `style.css`: de opmaak.
- `app.js`: het aanvraagformulier, filters en menu.
- `catalog.js`: de producten en gelegenheden in het formulier.
- `assets/`: productafbeeldingen.

## Lokaal bekijken

Open de map met een eenvoudige webserver, bijvoorbeeld:

```
npx serve .
```

## Let op

Dit is een demo. Het aanvraagformulier verstuurt nog niets: er is nog geen manier ingesteld waarop aanvragen binnenkomen.
